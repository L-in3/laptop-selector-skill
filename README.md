# 本命电脑推荐 Skill

帮助准大一新生根据录取专业推荐最匹配的笔记本电脑（本命电脑）。

## 这是什么？

一个帮你选笔记本电脑的智能 Skill，当你告诉它你的录取专业、预算和偏好后，它会：

1. 匹配专业需求知识库，分析你的专业四年真正需要什么配置
2. 联网搜索当前在售机型，实时获取价格和参数
3. 给出 3 台推荐（理想 / 平价 / 性价比），每台标注命中理由、一票否决项和浪费项
4. 附赠通用 + 专业专属避坑指南

核心理念：**本命度 = 需求命中率 / 价格浪费率**。不是推荐最贵的，而是推荐最适合你的。

## 触发方式

直接说出你的专业即可触发，例如：

- `我是软件工程的，买什么电脑？`
- `准大一，会计专业，预算4000`
- `本命电脑 大数据`
- `土木工程用什么笔记本`

不需要一次性提供所有信息，Skill 会引导你补充预算和偏好。

## 已覆盖专业

| 专业 | 大类 | 最吃配置 | 预算范围 |
|------|------|---------|---------|
| 计算机科学与技术 | 工科-计算机类 | 内存 > CPU | 2500 - 7000 |
| 视觉传达设计 | 艺术-设计类 | GPU > 屏幕色准 | 3000 - 7000 |
| 会计学 | 商科-财会类 | 便携 > 续航 | 2500 - 6000 |
| 土木工程 | 工科-土木/建筑类 | GPU > 数字小键盘 | 3000 - 7000 |
| 临床医学 | 医学-临床类 | 续航 > 便携 | 2500 - 6000 |

## 输出格式

每次推荐包含三部分：

- **专业需求简报**：你的专业四年核心场景 + 一句话定调
- **3 台平铺推荐**：每台含配置参数表（CPU / GPU / 内存 / 存储 / 屏幕 / 重量 / 续航）、命中理由、一票否决项、浪费项
- **避坑提醒**：通用避坑 + 专业专属避坑
